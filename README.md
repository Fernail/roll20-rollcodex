# RollCodex Roll20

Extension navigateur pour connecter une table Roll20 a RollCodex.

Fiche Chrome Web Store :
`https://chromewebstore.google.com/detail/rollcodex-roll20/janfigfnhmgimnbeklajfhaccgcngmpc`

## Utilisation

1. Installer l'extension depuis le Chrome Web Store.
2. Ouvrir une table Roll20.
3. Utiliser le panneau RollCodex dans Roll20 pour lier la table a un registre.
4. Envoyer une capture ou laisser l'auto-capture transmettre les messages visibles du chat.
5. Relire puis importer les donnees dans RollCodex.

## Donnees

L'extension transmet uniquement les messages Roll20 visibles, les speakers detectes, les indices de mapping et les mesures derivees utiles au registre choisi.

RollCodex ne deduit pas de narration, de scene ou d'intention MJ absente des logs.
